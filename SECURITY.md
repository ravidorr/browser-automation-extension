# Security Policy

## Reporting a vulnerability

Do not disclose vulnerabilities in public issues. Report them to [raanan@avidor.org](mailto:raanan@avidor.org) with a clear description, reproduction steps, affected version, and potential impact.

## Supported versions

Security fixes are provided for the latest released version.

## Response

Reports are acknowledged within five business days. The project will assess severity, coordinate remediation, and publish a fix or mitigation when appropriate.
